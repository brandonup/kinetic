---
name: start
description: Start a Kinetic work session. Checks Linear for assigned tickets and works on them automatically on a loop.
---

Check the Linear board for your assigned tickets. If you have a ticket in Todo status: move it to In Progress and start working on it. If you have a ticket that is Blocked: identify the blocking dependency, spawn the responsible agent as a subagent, and have them resolve it. If you have no Todo or Blocked tickets: do nothing.
